# MediaFlow 8.0.1.574

Two fixes. Matches the MediaFlow website v574.

- **Log a title (Batch Log): the XP preview now shows.** In 8.0.0 it was worked out in a way that failed silently, so "This log earns +N XP" never appeared. It now runs like the logging workspace's preview and matches what saving earns.
- **The logging workspace shows each title's chosen name** (Settings → Title names: English, Romanised Japanese…) instead of always the main name: titles in the log, their covers, the recommended title and Reroll history.
