# MediaFlow 6.0.1.565

A fix for Background Processes.

- **On every screen**: Background Processes, open or minimised, now stays on top of every page of the app (a title, Settings pages, Recovery and the rest), not only the main tabs. It steps aside while a dialog, sheet or menu is open.
- **Minimised icon next to the +**: on phones the icon sits right beside the +, at the same height, instead of floating above it.
- **The minimised icon can be dragged** anywhere, like the open widget. It follows the same settings: remember the position or go back to the default spot, and stay where dropped or snap to the nearest edge.
