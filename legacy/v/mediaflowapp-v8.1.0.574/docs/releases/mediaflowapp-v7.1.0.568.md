# MediaFlow 7.1.0.568

MediaFlow is now on **Mac and Linux** too. Matches the MediaFlow website v568, where both can be downloaded from Get MediaFlow.

## Mac
- `MediaFlow-7.1.0.568-macOS.dmg` (open it and drag MediaFlow to Applications) or the `.zip`. Apple silicon and Intel.
- The app is unsigned. The first time, open it, then go to System Settings → Privacy & Security and choose **Open Anyway**.

## Linux
- `MediaFlow-7.1.0.568-Linux-x86_64.AppImage`: make it executable (Properties → Allow executing, or `chmod +x`) and open it. Or unpack the `.tar.gz` and run `mediaflow`.
- 64-bit (x86_64); built on Ubuntu 22.04, so it runs on most current distributions.

## On both
- The same account, sync, logging, Library, Statistics and settings as on Windows.
- **Discord Rich Presence** when the Discord app is running (included when this build's Discord SDK has the Mac / Linux library).
- Get MediaFlow on the website and **Your devices** list each Mac and Linux PC with its version, and say when it needs an update.
- Not yet on Mac and Linux: the tray icon, starting with the computer, and timed notifications (Windows, Android and iOS keep them).
