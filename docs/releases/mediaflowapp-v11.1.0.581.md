# MediaFlow 11.1.0.581

Reorder a title's parts. Matches the MediaFlow website v581.

## Reorder a title's parts
Edit title → **By parts**: each part has a **drag handle**, **↑ / ↓** arrows and a **Position** number — drag a part, nudge it, or type where it goes (press Enter). The order is saved with the title (exactly as the website saves it), and every place that logs it follows it: the part chips and cards in Logging (Quick and Advanced) and Log any title. Each part keeps its own counter, unit and time per unit when it moves.
